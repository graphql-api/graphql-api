The organization is being modernized deliberately rather than treating repository presence as support.
The catalog below records the **migration state independently from npm publication state**.

Status meanings:

- **reference** — selected to prove the modern package contract;
- **migrate** — implementation worth porting onto current contracts;
- **audit** — upstream API/protocol must be verified before code migration;
- **repair** — repository/package identity is currently incorrect or copied;
- **scaffold** — incomplete/non-package repository;
- **historical** — useful evidence, but not a supported release target in its current form.

Every card includes a small animated data-flow diagram and an **illustrative modernization target**. Those examples deliberately do not claim that the legacy package already exposes that exact field.
